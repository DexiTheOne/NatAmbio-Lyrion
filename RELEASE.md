NatAmbio Alpha release for Lyrion 9 on Linux x86-64. Includes the browser Radar2 controls, live render telemetry, NAE and XTC bypass, NAE preamp, and per-player DSP history settings.

Radar2 now fills the browser window. The PCA field and technical readouts are visible as soon as the dashboard opens, and the panels stack on narrow screens. NAE and XTC have bypass switches in their headers, and DSP settings are available directly on the page.

The header groups player selection, Enable Alpha, Bypass All, Output Trim, and telemetry. The readouts stay aligned as values change, and the peak meter rises and falls smoothly between updates.

Add this release's `repo.xml` URL in Lyrion's Manage Plugins page, then enable Alpha for the desired FLAC-capable player in the plugin page. See the README for input formats, playback requirements, and history behavior.
