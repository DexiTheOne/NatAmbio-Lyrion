NatAmbio Alpha 0.1.16 corrects the radar cloud's left and right direction, steadies the cloud for diffuse and out-of-phase audio, and fades it for very quiet signals. The default RESPONSE for new player settings is 100 ms.

NatAmbio Alpha 0.1.15 uses verified tmpfs for temporary playback state when available. It skips DSP history saves when reset is enabled and avoids rewriting identical helper settings.

NatAmbio Alpha 0.1.14 colors the normal peak and buffer meter ranges green and gives Firefox slider and fader thumbs the same center stripe and shading as Chrome and Safari.

NatAmbio Alpha 0.1.13 collects radar and meter data only while a dashboard is polling. Collection and timeline writes stop after the viewer timeout. When a viewer returns, the meters resume as freshly measured audio reaches the playhead. Audio processing continues with the dashboard closed.

If NatAmbio Alpha is already installed, use Lyrion's Manage Plugins page to apply the update.
