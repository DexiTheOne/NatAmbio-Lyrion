NatAmbio Alpha release for Lyrion 9 on Linux x86-64. Includes the browser Radar2 controls, live render telemetry, NAE and XTC bypass, NAE preamp, and per-player DSP history settings.

Radar2 and the meters follow Lyrion's player playhead, with a per-stream telemetry timeline for gapless prefetch and seeks. The page shows how far ahead rendering is and when a live setting change is still queued behind buffered audio.

Add this release's `repo.xml` URL in Lyrion's Manage Plugins page, then enable Alpha for the desired FLAC-capable player in the plugin page. See the README for input formats, playback requirements, and history behavior.
